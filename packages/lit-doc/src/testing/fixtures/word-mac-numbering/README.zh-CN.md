# Word 原生十进制编号样本

Microsoft Word for Mac 16.109.2（16.109.26052523）在空白文档输入三段原创中英文，
全选并使用原生编号按钮，先保存 DOCX，再原生另存 Word 97-2004 DOC。
作者文字、动作、文件大小和摘要固定于 `manifest.json`，原创资产按 MIT 提供。

正文源码元为 27，段末 CP 为 10、17、27；原生 DOCX 使用同一具体实例的第零级，
十进制模板 `%1.`、起点 1、Tab suffix、440 twip 左缩进和 440 twip 悬挂。
九级 hybrid 定义整体保留，不以 QuireKit 内置 preset 替换。

原生画面显示 1/2/3；应用 AX 文本曾错误暴露 1/1/2，因此不作计数器预期。
DOCX 是同一应用的对照，不能当作另一个生产者，也不能据此宣称自有转换通过。
后续差异新增 fixture，不覆写本目录原件或摘要。
