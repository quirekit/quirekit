# @quirekit/accessibility

[English](./README.md) | 简体中文

为 QuireKit 编辑器提供屏幕阅读器需要的文档内容、选区信息和状态提示。

## 安装

```bash
npm install @quirekit/accessibility
```

## 使用方式

通过 `Accessibility` 扩展启用，再用 `getAccessibility(editor)` 读取或操作无障碍服务。应用仍需给编辑区域提供清楚的名称，并保证外围工具栏可以用键盘操作。
