# @quirekit/accessibility

English | [简体中文](./README.zh-CN.md)

Provides document content, selection information and status announcements for screen readers in QuireKit editors.

## Installation

```bash
npm install @quirekit/accessibility
```

## Usage

Enable the `Accessibility` extension and access its service through `getAccessibility(editor)`. Your app still needs a clear editor label and keyboard-accessible surrounding controls.
