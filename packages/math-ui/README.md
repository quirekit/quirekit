# @quirekit/math-ui

English | [简体中文](./README.zh-CN.md)

Vue interfaces for formula editing, including input, template selection and previews.

## Installation

```bash
npm install @quirekit/math-ui
```

The consuming project also needs: `vue` (^3.5.0).

## Usage

Use `MathAuthoringPanel` for a complete panel, or `MathEditorView` to compose your own interface. Create editing state with `@quirekit/math` and render it with `@quirekit/math-mathjax`.
