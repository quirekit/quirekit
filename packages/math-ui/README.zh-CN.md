# @quirekit/math-ui

[English](./README.md) | 简体中文

公式编辑器的 Vue 界面，包含公式输入、模板选择和预览。

## 安装

```bash
npm install @quirekit/math-ui
```

使用本包还需要：`vue` (^3.5.0)。

## 使用方式

使用 `MathAuthoringPanel` 创建完整编辑面板，或使用 `MathEditorView` 组合自己的界面。公式编辑状态由 `@quirekit/math` 创建，显示由 `@quirekit/math-mathjax` 提供。
