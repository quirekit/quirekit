# @quirekit/edit-history

[English](./README.md) | 简体中文

记录可查询的编辑活动，支持活动分类、分组和内容摘要。适合在应用中展示“谁在什么时候做了什么”。

## 安装

```bash
npm install @quirekit/edit-history
```

## 使用方式

先按活动数据类型记录事件，再用校验和分组工具整理显示。本包的活动记录与编辑器的撤销栈用途不同；持久化和用户信息由应用接入。
