# @quirekit/edit-history

English | [简体中文](./README.zh-CN.md)

Records queryable editing activity with categories, grouping and content summaries. Useful for showing who changed what and when.

## Installation

```bash
npm install @quirekit/edit-history
```

## Usage

Record events using the activity types, then use validation and grouping utilities to prepare a view. Activity records serve a different purpose from the editor undo stack. Your app connects persistence and user identities.
