# @quirekit/editor-ui

[English](./README.md) | 简体中文

为编辑器工具栏、建议列表、块菜单和拖动操作提供可复用的界面逻辑。

## 安装

```bash
npm install @quirekit/editor-ui
```

## 使用方式

自建编辑器界面时按功能使用根入口的控制器；Vue 界面从 `@quirekit/editor-ui/vue` 导入。文档的实际修改仍通过 Core 命令完成。
