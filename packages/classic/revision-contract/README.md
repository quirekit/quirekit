# @quirekit/classic-revision-contract

English | [简体中文](./README.zh-CN.md)

Lets extensions describe data that participates in Word tracked changes without loading the complete revision engine.

## Installation

```bash
npm install @quirekit/classic-revision-contract
```

## Usage

Use its addWordRevisions types and attribute helpers when authoring a revision-aware extension. The classic-revision package records, accepts and rejects changes. Ordinary applications usually access these features through a Classic Word preset.

## Things to know

- This is not a review panel and does not enable tracking by itself.
