# @quirekit/extension-floating-object

English | [简体中文](./README.zh-CN.md)

Stores movable, resizable floating objects and their geometry.

## Installation

```bash
npm install @quirekit/extension-floating-object
```

## Usage

Install FloatingObject in Core. Your application supplies content and controls, and the chosen view must support presentation and dragging. For Word pictures, shapes and text wrapping, use classic-floating-object.

- This is document content, not a general-purpose HTML popup.
