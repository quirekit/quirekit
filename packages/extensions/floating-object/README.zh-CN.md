# @quirekit/extension-floating-object

[English](./README.md) | 简体中文

在文档中保存可移动、缩放的浮动对象及其位置、大小。

## 安装

```bash
npm install @quirekit/extension-floating-object
```

## 使用方式

将 FloatingObject 加入 Core 的扩展。应用提供对象内容及操作入口；显示和拖动需要所选视图支持。需要 Word 图片、形状和环绕文字时，应使用 classic-floating-object。

## 使用时注意

- 这不是任意 HTML 的浮动窗口，也不代替应用的弹窗组件。
