# @quirekit/ai-runtime

English | [简体中文](./README.zh-CN.md)

Core services for AI to read and edit documents, including the document view, block targeting, editing tools and error messages.

## Installation

```bash
npm install @quirekit/ai-runtime
```

## Usage

Applications use the editor AI service or the public document SDK. Extensions describe readable content with `addAiCapabilities()` and callable commands with `defineCommand`.

## Things to know

- For a complete product setup, start with Classic AI or Md Editor AI. Installing this package does not configure a working model by itself.
