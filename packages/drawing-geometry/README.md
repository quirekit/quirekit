# @quirekit/drawing-geometry

English | [简体中文](./README.zh-CN.md)

Calculates paths, connection points and text areas for document shapes so display and export use the same definitions.

## Installation

```bash
npm install @quirekit/drawing-geometry
```

## Usage

Check a shape name with `isDrawingPreset()`, then use `resolveDrawingPreset()` with dimensions and adjustment values to calculate geometry. It returns data and does not create a canvas or editor.
