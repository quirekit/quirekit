# @quirekit/suggestion

[English](./README.md) | 简体中文

管理输入时弹出的建议列表，例如 @ 提及、/ 命令和搜索补全。

## 安装

```bash
npm install @quirekit/suggestion
```

## 使用方式

使用 `SuggestionController` 管理候选项、当前选中项和确认操作，再把状态显示到你的列表组件中。候选数据和最终插入动作由应用提供。
