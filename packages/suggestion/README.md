# @quirekit/suggestion

English | [简体中文](./README.zh-CN.md)

Manages suggestions shown while typing, such as @ mentions, / commands and search completions.

## Installation

```bash
npm install @quirekit/suggestion
```

## Usage

Use `SuggestionController` for candidates, the active item and confirmation, then render its state in your list component. Your app supplies candidates and the final insertion action.
