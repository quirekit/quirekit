# @quirekit/accessibility-contract

English | [简体中文](./README.zh-CN.md)

Defines accessibility data types shared by document features and user interfaces.

## Installation

```bash
npm install @quirekit/accessibility-contract
```

## Usage

Import the types with `import type`. This package describes data; it does not create a screen-reader interface or browser event handlers. Use Accessibility for the runtime service.
