# @quirekit/accessibility-contract

[English](./README.md) | 简体中文

定义无障碍相关的数据类型，让文档功能包和界面能描述同一份可访问内容。

## 安装

```bash
npm install @quirekit/accessibility-contract
```

## 使用方式

用 `import type` 引入需要的类型。这里只描述数据，没有屏幕阅读器界面或浏览器事件处理；需要运行时服务时使用 Accessibility 包。
