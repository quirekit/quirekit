# @quirekit/msfe-html-sandbox

English | [简体中文](./README.zh-CN.md)

Stores isolated HTML examples in MSFE using html-preview fences.

## Installation

```bash
npm install @quirekit/msfe-html-sandbox
```

## Usage

Add MsfeHtmlSandbox to extensions and configure the html-sandbox runner and preview component. Use readHtmlSandboxSource and patchHtmlSandboxSource to read or update a fence.

## Things to know

- The application explicitly enables execution; a preview cannot directly edit the Markdown editor.
