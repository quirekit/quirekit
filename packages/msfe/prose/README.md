# @quirekit/msfe-prose

English | [简体中文](./README.zh-CN.md)

Provides Markdown prose features including emphasis, inline code, strikethrough, quotes, lists, task checkboxes and tables.

## Installation

```bash
npm install @quirekit/msfe-prose
```

## Usage

This package contains several extensions. StarterKit combines the usual features. For custom setups choose Emphasis, InlineCode, Table, TaskItem and others; the package itself is not one extension.

## Things to know

- Table editing changes Markdown table source. It is not a database-style data-view.
