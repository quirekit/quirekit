# @quirekit/msfe-prose

[English](./README.md) | 简体中文

提供 Markdown 正文的斜体、行内代码、删除线、引用、列表、任务框和表格等基础显示与操作。

## 安装

```bash
npm install @quirekit/msfe-prose
```

## 使用方式

本包包含多个独立扩展。StarterKit 已经组合了常用项；自行配置时可选择 Emphasis、InlineCode、Table、TaskItem 等，而不是把整个包作为一个扩展安装。

## 使用时注意

- 表格编辑会修改 Markdown 表格源码；这不是具有数据库字段、筛选视图的 data-view。
