# @quirekit/msfe-html

English | [简体中文](./README.zh-CN.md)

Recognizes HTML fragments in MSFE and optionally shows sanitized static content.

## Installation

```bash
npm install @quirekit/msfe-html
```

## Usage

Add Html to extensions. Use setHtmlRendering to change presentation without rewriting Markdown. Use html-sandbox separately for HTML examples that need scripts.

## Things to know

- Static HTML previews do not execute scripts. Application policy controls resource loading.
