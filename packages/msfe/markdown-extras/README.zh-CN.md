# @quirekit/msfe-markdown-extras

[English](./README.md) | 简体中文

为 MSFE 补充脚注、公式、提示块、Frontmatter、Mermaid 等可选 Markdown 语法。

## 安装

```bash
npm install @quirekit/msfe-markdown-extras
```

## 使用方式

按需要把 Footnotes、Math、Callout、Frontmatter、Mermaid、TextDiagrams 等加入 extensions。它们不在基础 StarterKit 中。需要公式或图形预览时，使用对应 renderer 配置；只想显示源码时不必加载绘图界面。

## 使用时注意

- 这些语法并非所有 Markdown 阅读器都支持。向其他系统分享时，应确认对方支持相应语法。
