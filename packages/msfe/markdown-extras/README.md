# @quirekit/msfe-markdown-extras

English | [简体中文](./README.zh-CN.md)

Adds optional Markdown features such as footnotes, math, callouts, frontmatter and Mermaid to MSFE.

## Installation

```bash
npm install @quirekit/msfe-markdown-extras
```

## Usage

Add Footnotes, Math, Callout, Frontmatter, Mermaid, TextDiagrams or other features to extensions as needed. They are not in the base StarterKit. Configure the corresponding renderer for formula or diagram previews; displaying source does not require a graphical workspace.

## Things to know

- Not every Markdown reader supports these syntaxes. Check the receiving system when sharing documents.
