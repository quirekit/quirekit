# @quirekit/unocss-preset

English | [简体中文](./README.zh-CN.md)

Styles and an UnoCSS preset for QuireKit UI. Import the prebuilt CSS directly or integrate it into an existing UnoCSS build.

## Installation

```bash
npm install @quirekit/unocss-preset
```

## Usage

Applications without UnoCSS can import the stylesheet below. For UnoCSS projects, configure `presetQuireKit()` or `defineQuireKitUnoConfig()`.

```ts
import '@quirekit/unocss-preset/quirekit.css'
```

## Things to know

- CSS supplies the appearance. Import Vue components from `@quirekit/ui/vue`.
