# @quirekit/pm-decoration

[English](./README.md) | 简体中文

描述高亮、节点样式和临时控件的位置，不把这些显示效果写入正文。

本包在 `@quirekit` 名下维护 ProseMirror 的对应能力，供 QuireKit 及其扩展使用。

## 安装

```bash
npm install @quirekit/pm-decoration
```

## 使用方式

用 DecorationSet 保存一组显示标记，文档修改后按事务映射位置。

常用入口：Decoration、DecorationSet。

## 使用时注意

- 同一个编辑器使用同一组 @quirekit/pm-* 包，不要混用官方 prosemirror-* 实例，否则节点、选区或插件可能来自不同的包实例。
- 需要完整编辑器时，从 Core 和 StarterKit 开始即可，不必逐个组合底层包。
