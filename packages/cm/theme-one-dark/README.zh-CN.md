# @quirekit/cm-theme-one-dark

[English](./README.md) | 简体中文

为 CodeMirror 提供 One Dark 深色主题与相应语法高亮颜色。

## 安装

```bash
npm install @quirekit/cm-theme-one-dark
```

## 使用方式

把 oneDark 加入编辑器的 extensions。它影响编辑区域的外观，不改变源码或整页应用主题。

## 使用时注意

- 由 `@codemirror/theme-one-dark` 6.1.3 的源码维护而来；来源和本地差异记录在 UPSTREAM.json。
- 同一实例统一使用 @quirekit/cm-* 包，不与官方 @codemirror/* 的实例混用。
