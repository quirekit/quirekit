# @quirekit/cm-theme-one-dark

English | [简体中文](./README.zh-CN.md)

Provides a One Dark theme and syntax-highlighting colors for CodeMirror.

## Installation

```bash
npm install @quirekit/cm-theme-one-dark
```

## Usage

Add oneDark to the editor’s extensions. It styles the editing surface without changing source text or the application’s overall theme.

## Things to know

- Maintained from `@codemirror/theme-one-dark` 6.1.3; UPSTREAM.json records its origin and local changes.
- Use @quirekit/cm-* consistently within an editor rather than mixing official @codemirror/* instances.
