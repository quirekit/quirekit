# @quirekit/cm-language

English | [简体中文](./README.zh-CN.md)

Provides shared CodeMirror tools for parsing, highlighting, indentation and folding.

## Installation

```bash
npm install @quirekit/cm-language
```

## Usage

Usually start with a language package such as cm-lang-javascript. Use LanguageSupport, LRLanguage or StreamLanguage when authoring language support.

## Things to know

- Maintained from `@codemirror/language` 6.12.4; UPSTREAM.json records its origin and local changes.
- Use @quirekit/cm-* consistently within an editor rather than mixing official @codemirror/* instances.
